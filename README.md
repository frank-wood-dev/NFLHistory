# NFL History

A personal NFL historical database and analytics platform covering the Super Bowl era.

## Overview

NFL History is a long-term project focused on historical NFL analysis. It combines a PostgreSQL database, data import tools, SQL reporting, and a modern Java REST API to explore games, teams, franchises, coaches, and historical trends.

## Technologies

- Java 21
- Spring Boot
- Spring JDBC
- PostgreSQL
- SQL
- JavaScript (Data Import)
- Git / GitHub

## Current Features

- Historical game database
- Franchise and team modeling
- JavaScript data import pipeline
- SQL reporting
- Franchise rankings
- Head-to-head rivalry analysis
- Spring Boot REST API (in progress)

## Planned Features

- REST endpoints for historical data
- Team rankings by era
- Historical game search
- Coach statistics
- Turnover and scoring research
- React web application
