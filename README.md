# NFL History

A personal NFL historical database and ranking engine.

## Overview

This project models NFL games, historical teams, and franchises beginning with the Super Bowl era.

## Technologies

- JavaScript
- PostgreSQL
- SQL

## Current Features

- Historical game database
- Franchise and team modeling
- SQL reporting
- Franchise rankings
- Head-to-head rivalry analysis
- Import data
  
## Planned Features

- Franchise rankings
- Team rankings by era
- Head-to-head rivalry reports
- Historical game analysis
- Turnover and scoring research
